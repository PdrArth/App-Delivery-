# Meu  App-Deliviry 

Este é um aplicativo de entrega que utiliza o banco de dados Firebase para realizar o cadastro e login de usuários. O projeto oferece funcionalidades de alteração de nome e foto de perfil diretamente dentro do aplicativo, proporcionando uma experiência personalizada para os usuários.

Infelizmente, o desenvolvimento do projeto foi interrompido devido a dificuldades com o Firebase Storage, que não está aceitando os meios de pagamento necessários para a continuidade do projeto. Como resultado, não foi possível implementar a funcionalidade de listagem de produtos, limitando o alcance completo da aplicação.
